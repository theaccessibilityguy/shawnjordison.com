# shawnjordison.com

Personal website for Shawn Jordison, published with GitHub Pages at https://shawnjordison.com.

## How to update
- Edit the files on the main branch. GitHub Pages republishes automatically within a few minutes.
- index.html is the homepage. story.html is the My story page. styles.css holds the shared design.
- Keep the CNAME file (it must contain shawnjordison.com).
- Contact address: shawn@theaccessibilityguy.com
- Public wording, especially on story.html, must be approved by Shawn before publishing.
- After changes, recheck mobile layout, keyboard navigation, and links.

## DNS
DNS is managed in GoDaddy. Only the root A/AAAA records, the www CNAME, and the GitHub verification TXT record relate to this site. Do not change the Microsoft 365 email records (MX, SPF, autodiscover, and related records).
